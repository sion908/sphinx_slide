本のざっくりした話
======================================================================

『冒険の書』は、学校や勉強を問い直す本
----------------------------------------------------------------

.. container:: flex

    .. container:: size-1

        **本の問い**

        * なぜ学校に行くのか
        * なぜ勉強するのか
        * 好きなことだけしてはいけないのか
        * **AI時代に何を学ぶのか**

    .. container:: size-1

        **読みながら思ったこと**

        * 問いの立て方は面白い
        * 学校や能力主義を疑う姿勢もわかる
        * でも、そのまま飲み込めない
        * **AIができるから、そこがいるのでは？**


引っかかったところ
======================================================================

学校教育批判には乗り切れない
----------------------------------------------------------------

本書では、学校が秩序や服従を作る装置として語られる。

.. revealjs-fragments::
    * その指摘自体はわからなくもない
    * 学校を神格化しすぎた面もあると思う
    * でも、学校教育をそこまで否定的には見られなかった


なぜ乗り切れないのか
----------------------------------------------------------------

.. container:: flex

    .. container:: size-1

        **子ども側**

        * まだ何も知らない
        * 娯楽が多い
        * 自分から学びに向かえるとは限らない

    .. container:: size-1

        **大人側**

        * 自由な学びを支えるのは難しい
        * 全員が優秀な教育者になれるわけではない
        * 最初に何を渡すかは重い

.. revealjs-fragments::
    **自由に学べばいい、だけでは足りない気がした**


基礎はやっぱり大事
======================================================================

四則演算は大事
----------------------------------------------------------------

本書では、基礎という考え方が学びを型にはめてしまう、という話が出てくる。

これは少しわかる。

.. revealjs-fragments::
    * AI時代は、必要なところから学ぶほうが速い
    * 大学以降の学びも、目的から逆算する
    * 全部を網羅してから進んでいたら追いつかない

でも。

.. revealjs-fragments::
    **それができるのは、基礎があるからではないか**

.. revealjs-fragments::
    **AIが計算できるからこそ、四則演算の意味を理解する必要がある**


型を知っているから崩せる
----------------------------------------------------------------

.. container:: flex

    .. container:: size-1

        **高校まで**

        * 範囲が決まっている
        * テストに出る
        * まずは全部やる

    .. container:: size-1

        **大学以降**

        * 目的が先にある
        * 足りないところを学ぶ
        * 必要に応じて掘る

.. revealjs-fragments::
    **高校までの勉強は、勉強の仕方の筋トレだったのかもしれない**

.. revealjs-fragments::
    **AIが答えを出せるからこそ、問いを立てる力が必要**


学力を保険として見ている
======================================================================

学歴や看板の効き方
----------------------------------------------------------------

会社員といいながら、個人事業主的に生きている感覚がある。

そういう働き方をしていると、高校や大学の看板がまだ後ろにあるように感じる。

.. revealjs-fragments::
    * この人は一定の負荷に耐えたはず
    * やるべきことをやれるはず
    * 最低限の信用の足場になる

.. revealjs-fragments::
    **能力主義や学歴を、簡単に悪いものとは言えない**

.. revealjs-fragments::
    **AIが何でもできる時代だからこそ、人間の信用が問われる**


子どもに渡したくなるもの
----------------------------------------------------------------

たぶん自分は、子どもにこう思う。

.. revealjs-fragments::
    * 天才ではないなら
    * 誰でもやれば身につくはずの学力は持っていてほしい
    * 難しいことに向き合う経験をしてほしい
    * 面倒でも続ける経験をしてほしい

.. revealjs-fragments::
    **そのまま本書で批判される親になりそう**

.. revealjs-fragments::
    **AIが答えをくれるからこそ、答えを探す経験が必要**


ポジショントークでは、と思った
======================================================================

著者への違和感
----------------------------------------------------------------

「好きなことを探究する」

「世界は自ら変えられる」

言葉としては魅力的。

でも、読みながらずっと思っていた。

.. revealjs-fragments::
    **それを言える立場の人だからでは？**


自由に外れるには資本がいる
----------------------------------------------------------------

.. container:: flex

    .. container:: size-1

        **外れても生きられる人**

        * 信用がある
        * 人脈がある
        * 失敗しても戻れる場所がある
        * 自分で場を作れる

    .. container:: size-1

        **普通の人にとっての学校**

        * 最低限の道具を受け取る場所
        * 読み書き、計算
        * 面倒なことをやる経験
        * 社会に出るための足場

.. revealjs-fragments::
    **だから、学校教育を批判する言葉には乗り切れなかった**


でも、アンラーニングは必要
======================================================================

子どもではなく、大人の学びとして
----------------------------------------------------------------

ここから少し納得した。

本書の学び方は、義務教育の代わりではなく、
社会に出たあとに必要になる学びに近いのではないか。

.. revealjs-fragments::
    * 基礎を身につける
    * 社会に出る
    * 現実にぶつかる
    * 自分の問いが見えてくる
    * そこで学び直す

.. revealjs-fragments::
    **AIが答えを出せるからこそ、問いを問い直す必要がある**


アンラーニングの受け取り方
----------------------------------------------------------------

自分にとってのアンラーニングは、

.. revealjs-fragments::
    * 学校なんていらないと思うことではない
    * 基礎教育を否定することでもない
    * 学んできたものを絶対視しないこと
    * 基礎を持った大人が、次に進むための学び方

.. revealjs-fragments::
    **捨てるというより、問い直す**

.. revealjs-fragments::
    **AIができるから、人間がやるべきことを問い直す**


AIができないこと
======================================================================

人間にしかできないこと
----------------------------------------------------------------

AIができることと、人間にしかできないこと。

.. container:: flex

    .. container:: size-1

        **AIができる**

        * 既知のパターン認識
        * 大量の情報処理
        * 答えの生成
        * 効率化

    .. container:: size-1

        **人間にしかできない**

        * 問いを立てる
        * 価値を判断する
        * 文脈を理解する
        * 偶然を意味に変える

.. revealjs-fragments::
    **AIが答えを出せるからこそ、問いを立てる人間がいる**

問い直すには、たぶんセレンディピティがいる。

    * 自分の問いが更新される

.. revealjs-fragments::

.. revealjs-fragments::

長崎でもやれる
======================================================================

隔離された地でも
----------------------------------------------------------------

長崎は、地理的には少し隔離されている。

東京や福岡のように、毎日のように大きな技術イベントがあるわけではない。

でも、だからこそ場を作る意味がある。

.. revealjs-fragments::

    * 自分たちで持ち寄る
    * 小さい発見を共有する
    * 偶然に出会う確率を上げる
